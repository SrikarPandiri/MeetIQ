Getting Started

Paste raw meeting notes, choose the summary detail level, then analyze the notes to generate a structured recap.

  • Use raw bullets, transcripts, or rough call notes.
  • Review unclear fields marked as Not specified.
  • Copy the final recap for Slack, email, or project tools.

Output Rules

MeetIQ should extract only information present in the notes and avoid inventing owners, tasks, dates, or decisions.

  • Missing owner: Owner is Not specified.
  • Missing deadline: Deadline is Not specified.
  • Ambiguous decision: keep it under questions or risks.

AI Integration Guide

Connect the Analyze Notes action to an AI API and request structured JSON for summaries, decisions, deadlines, and tasks.

  • Validate JSON before rendering it in the UI.
  • Store the original source text with each extracted item.
  • Use confidence labels for uncertain extractions.
